Claude Code

Token erzeugen – einmalig, gilt rund ein Jahr:
1. Terminal öffnen, wo du in Claude Code angemeldet bist. Das geht auch im Container: Coolify → diese Ressource → Terminal.
2. claude setup-token ausführen und dem Link folgen.
3. Den Token (sk-ant-oat01-…) oben unter Zugänge ins Feld Claude-Code-Token einsetzen und speichern.
Nicht verwechseln: Ein API-Key (sk-ant-api…) geht hier nicht – der läuft über die Token-Abrechnung, nicht über dein Abo.
